## 🚀 Ход выполнения работы

### 1. Создание учётной записи на GitHub
Регистрация выполнена на сайте [github.com](https://github.com). Указаны `username`, `email`, `пароль`.

### 2. Создание репозитория на GitHub
`New repository` → имя `git-practice` → Public → `Create repository`.

Получен URL: `https://github.com/<username>/git-practice.git`
